# 后续路线

当前 `0.4.0-alpha` 已经能完整跑通一局，但表现层仍是程序化几何。
以下按「对"像不像"影响最大」排序。

## P0 — 表现层（差距最大的部分）

1. **材质与贴图**：为地形、建筑、武器生成程序化贴图（噪声 + 边缘磨损），替换纯色材质。
2. **角色骨骼动画**：把程序化关节换成 `Skeleton3D` + `AnimationTree`，加入待机/跑/跳/瞄准/换弹/倒地混合树。
3. **音效**：脚步、枪声（按武器区分）、换弹、命中、建造、编辑、风暴环境音、UI 音。
4. **命中与击杀反馈**：屏幕方向受击指示、击杀确认、连杀提示。
5. **粒子**：枪口烟雾、弹壳抛落、脚步尘土、建筑碎裂碎块。

## P1 — 玩法完整性

6. **投掷物**：破片手雷、烟雾、诱饵、冲击雷。
7. **移动扩展**：载具、游泳、攀爬、滑索。
8. **精英据点**：每个 T2/T3 据点一名精英守卫 + 权限卡 + 地下金库。
9. **更多建筑交互**：可破坏门窗、可拾取家具、地下室。
10. **观战与录像**：被淘汰后可观战剩余 AI。

## P2 — AI 深度

11. **NavigationServer3D**：烘焙导航网格，替换直线移动。
12. **分层行为树 / 环境查询**：感知、移动、战斗、建造、资源分层决策。
13. **建造对抗**：抢墙、编辑对射、反制高地、封顶压枪。
14. **小队协同**：AI 之间共享情报、交叉火力、互相掩护。
15. **难度曲线**：按剩余人数动态调整技能。

## P3 — 工程与交付

16. **导出可执行包**：为 Windows/Linux 构建导出版本，附导出模板说明。
17. **MultiMesh / LOD / 遮挡剔除**：支撑 60+ AI 与更大地图。
18. **设置持久化扩展**：键位重绑定、画质档位、手柄支持。
19. **自动化测试**：地形生成、建造合法性、编辑拓扑、AI 状态的单元测试。
20. **性能预算**：帧时间分项统计与回归基准。
