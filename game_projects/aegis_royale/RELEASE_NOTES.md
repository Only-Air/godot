# Aegis Royale 0.3.1-alpha

## 重要修复

这是针对预编译稳定版 Godot 无法启动上一发行包的兼容修复版。

- 将项目兼容目标从未发布的 `4.8 dev` 改为官方 `Godot 4.5 stable`。
- 修复 GDScript Variant 类型推断导致的脚本解析失败。
- 修复 `CombatProjectile.gravity` 与 `Area3D` 原生成员冲突。
- 修复动态创建玩家时 `current_scene` 尚未建立造成的空引用。
- 修复 AI 动态建造节点的场景树挂载。
- 使用官方预编译 `Godot 4.5.1 stable` 完成编辑器导入测试。
- 完成自动开局运行时冒烟测试：生成 8 个战斗单位、71 个战利品，AI 实际生成 5 个建造结构，测试过程无项目脚本错误。

## 运行方法

1. 安装官方预编译 Godot 4.5.1 stable 或兼容的 4.5.x 版本。
2. 解压 `AegisRoyale-0.3.1-alpha-GodotProject.zip`。
3. 启动 Godot Project Manager。
4. 点击“导入”，选择解压目录中的 `project.godot`。
5. 等待首次扫描完成，点击右上角运行按钮或按 `F6/F5`。
6. 在大厅点击“开始离线比赛”。

不要直接双击 `project.godot` 并期待操作系统自行启动游戏；应先用 Godot Project Manager 导入项目。

## 本版本内容

- 32 个默认战斗单位，可在本地档案调整 AI 数量。
- 空中自由落体、滑翔、九个原创兴趣点、中央湖和河网。
- 五槽物品栏、12 类武器、稀有度、弹药、治疗和护盾。
- 木/石/金属采集、结构成型、耐久和建造预览。
- 墙、地板、斜坡、锥顶，以及墙体 3×3 编辑拓扑。
- AI 搜刮、武器评分、转点、治疗、搭墙、建盒和斜坡推进。
- 瞄准收束、移动扩散、射击热扩散、后坐力、爆头和距离衰减。
- 火箭投射物、爆炸衰减及范围结构伤害。

## 已知限制

- 当前是 Godot 项目源码包，不是 Windows `.exe`。
- 灰盒视觉与程序生成占位建筑。
- 尚未完成角色和武器动画、音频与完整特效。
- AI 暂未接入 NavigationServer3D，复杂室内路径可能失败。
