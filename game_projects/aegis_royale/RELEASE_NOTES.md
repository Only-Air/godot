# Aegis Royale 0.3.0-alpha

## 定位

完全离线的原创建造大逃杀垂直切片，运行于本仓库的 Godot 4.8 开发版。发行包只包含独立游戏工程，不包含完整 Godot 引擎源码或第三方游戏资产。

## 本版本内容

- 32 个默认战斗单位，可在本地档案调整 AI 数量。
- 空中自由落体、滑翔、九个原创兴趣点、中央湖和河网。
- 五槽物品栏、12 类武器、稀有度、弹药、治疗和护盾。
- 木/石/金属采集、结构成型、耐久和建造预览。
- 墙、地板、斜坡、锥顶，以及墙体 3×3 编辑拓扑。
- 普通与简易建造/编辑模式。
- AI 搜刮、武器评分、转点、治疗、搭墙、建盒和斜坡推进。
- 偏移安全区、胜负结算、本地设置与生涯存档。
- 瞄准收束、移动扩散、射击热扩散、后坐力、爆头和距离衰减。
- 火箭投射物、爆炸衰减及范围结构伤害。

## 运行

1. 解压发行包。
2. 使用 Godot 4.8 编辑器导入包内的 `project.godot`。
3. 运行 `main.tscn`。

当前包是 Godot 项目源码包，不是已导出的 Windows/Linux 可执行文件。后续在确定自定义引擎二进制和导出模板后，再增加平台可执行包。
