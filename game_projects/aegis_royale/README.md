# Aegis Royale Prototype

这是一个放在 Godot 4.8 源码仓库中的独立原创游戏工程，用于验证战术大逃杀、模块化建造/编辑和战术 AI。它不包含或复制任何第三方游戏的地图、角色、美术、声音、商标或专有界面资产。

## 当前可玩内容

- 原创群岛竞技场原型与大厅入口
- 第三人称移动、冲刺、跳跃、射线武器、弹匣和护盾
- 6 类原创武器数据池
- 动态缩圈、圈外持续伤害、存活人数 HUD
- 墙、地板、斜坡、屋顶四类建造件
- 准星编辑、旋转、材料消耗
- `V` 一键切换简易建造和简易编辑
- 15 个会索敌、控制交战距离、横向走位、射击、搭墙和低生命建盒的 AI
- 原创大厅及基础设置弹窗

## 启动

用本仓库编译出的 Godot 4.8 编辑器导入：

`game_projects/aegis_royale/project.godot`

然后运行主场景。

## 操作

- `WASD`：移动
- `Shift`：冲刺
- `Space`：跳跃
- 鼠标左键：射击 / 放置结构
- `R`：换弹
- `Q`：切换战斗和建造
- `1/2/3/4`：墙 / 地板 / 斜坡 / 屋顶
- `G`：旋转结构
- `F`：编辑准星指向的结构
- `V`：切换简易建造与简易编辑
- `Esc`：释放或捕获鼠标

## 工程定位与后续路线

当前版本是无外部资产依赖的垂直切片骨架，便于直接运行和继续开发。生产级项目仍需：网络权威服务器、客户端预测与回滚、动画状态机、真实物品拾取、完整库存、载具、地形流送、导航网格、行为树/EQS、反作弊、性能预算、原创角色和场景资产，以及全面测试。

推荐后续里程碑：

1. 将地图拆分为原创生物群系与兴趣点，并使用 MultiMesh/LOD/遮挡剔除。
2. 把 BuildPiece 改造成网格占位、预览合法性检测、所有权及服务器确认模型。
3. 实现窗口/门/半墙/角切等网格级编辑状态，并加入编辑确认/重置。
4. 引入 NavigationServer3D 与分层 AI：感知、移动、战斗、资源、建造和风暴决策。
5. 使用 Godot MultiplayerAPI 建立专用服务器原型，先从 8–16 人压力测试开始。
6. 建立原创 UI 设计系统、键鼠/手柄重绑定及无障碍选项。
