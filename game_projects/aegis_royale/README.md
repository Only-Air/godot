# Aegis Royale

完全离线的原创第三人称建造大逃杀，运行于 **Godot 4.5.1 stable**（Forward+）。

这一版是**重做版**：上一版只是灰盒占位，本版重建了地形、角色、武器、建造、AI 与界面。

---

## 正确启动方式

1. 下载官方预编译 **Godot 4.5.1 stable**（Standard 版）。
2. 解压本项目压缩包。
3. 打开 Godot Project Manager → **导入** → 选择 `project.godot`。
4. 等待首次扫描完成，按 `F5` 运行。
5. 在大厅点击 **开始比赛**。

> `project.godot` 是工程配置，不是可执行文件。请从 Project Manager 导入，不要双击当作 `.exe`。

若显卡不支持 Vulkan，可在 `project.godot` 里把
`renderer/rendering_method` 改为 `gl_compatibility`。

## 这一版做了什么

### 地形与地图（不再是平地）

- 真实高度场地形：`FastNoiseLite` 多层噪声 + 海岸衰减 + 中央高地。
- 320 × 320 m 岛屿，100 × 100 网格（约 3.2 m/格），三角网格 + `ConcavePolygonShape3D` 碰撞。
- 顶点色按高程与坡度混合：沙滩 / 草地 / 岩石 / 雪线，并叠加山体阴影。
- 兴趣点区域会**自动削平成平台**，道路沿线也会削平，保证建筑不会悬空或埋进山里。
- 水面平面、雾气、程序化天空、SSAO、Glow、Filmic 色调映射。

### 可以走进去的建筑

建筑不是实心方块，而是由 `BuildingKit` 用真实构件拼装：

- 四面墙带**门洞**和**窗洞**（窗框 + 半透明玻璃）。
- 楼板、内部**楼梯**、屋顶或女儿墙。
- 多层的**塔楼**、带栏杆的**瞭望塔**、带天窗桁架的**仓库**。
- 集装箱、路障、护栏。

### 角色模型与动画

- 程序化人形骨架：髋、躯干、头、双肩、双肘、双腿、双膝，共 20+ 构件。
- 程序化动画状态：行走/奔跑摆臂摆腿、膝盖屈伸、躯干起伏、瞄准举枪、下蹲、空中姿态、倒地。
- 第三人称越肩镜头（`SpringArm3D`），瞄准时自动拉近并收窄 FOV。

| 破阵泵动霰弹枪 | 霰弹 | 霰弹 | 单发爆发，拆板强 |

| 旋风冲锋枪 | 冲锋枪 | 轻型 | 贴脸压制 |
| 低语消音冲锋枪 | 冲锋枪 | 轻型 | 隐蔽突袭 |
| 制式手枪 | 手枪 | 轻型 | 落地过渡 |
| 暗影消音手枪 | 手枪 | 轻型 | 潜行点射 |
| 哨兵栓动狙击枪 | 狙击 | 重型 | 远距离一枪 |

射击系统包含：

- 6 级稀有度（普通 → 特制），影响伤害、换弹与掉落权重。
- 弹匣、备弹、换弹时间、三连发。
- **后坐力**：垂直上跳 + 镜头自动回正。
- **扩散**：移动、跳跃、连射热量、瞄准、下蹲分别影响。
- **距离衰减**：每把武器独立的衰减起点、终点与最低倍率。
- **爆头 1.85 倍**伤害。
- **建筑伤害倍率**：霰弹拆板强、重狙拆板极强。
- 曳光弹、枪口火光与动态光源、命中火花、碎屑、烟尘、爆炸冲击波与扩散环。

### 建造系统

- 4 m 水平网格、3 m 垂直层高。
- 四种结构：**墙、地板、斜坡（棱柱）、锥顶（四棱锥）**。
- **墙与地板是真正的 3×3 单元网格**，逐格生成独立网格与碰撞体。
- 建造预览幽灵：蓝色可放置，红色不可放置，并给出原因（材料不足/超出范围/已被占用/位于地形内）。
- **按住左键连发建造**（0.075 s 节流），与移动配合可以边走边搭板。
- 三种建材：木材（150 耐久 / 快）、石材（300）、金属（500 / 慢）。
- 结构有**成型动画**与受击闪白，耐久归零后碎裂并返还少量材料。

### 编辑系统（真正的选格编辑）

- 对准自己的墙或地板按 `F` 进入编辑模式。
- 屏幕空间叠加 **3×3 网格**，鼠标指向哪一格就高亮哪一格。
- 左键**开关该格**，`F` 确认，`Esc` 取消并还原。
- 预设拓扑：完整 / 窗口 / 门 / 拱门 / 半墙 / 低墙 / 左门 / 右门 / 支柱 / 阶梯。
- 编辑后视觉与碰撞都会重建，所以开窗后真的可以射击、开门后真的可以通行。

### AI

31 名 AI（可在设置里调到 63），每个都有独立的技能与性格（均衡 / 激进 / 建造型 / 远射型 / 谨慎）。

感知层：
- 视锥 + 视距（46–92 m，随技能变化）。
- 真实**视线检测**（射线被地形或建筑挡住就看不见）。
- 目标记忆（丢失目标后仍会朝最后已知位置推进数秒）。
- 反应延迟（0.11–0.52 s）与瞄准误差（随距离放大、随技能收敛）。
- 射击提前量预判（按弹速与目标速度计算）。

决策层（效用状态机）：
- `搜刮`：扫描地面战利品，按武器评分决定是否值得去捡，同时搜索宝箱。
- `转点`：风暴临近时优先进入安全区，并按半径向内收缩落点。
- `交战`：维持武器理想交战距离、左右横移、必要时后撤。
- `推进`：近距离且偏激进时，边前进边搭「墙 + 斜坡」抢高。
- `防御`：血量过低时**四面建盒**自保、使用恢复品，恢复后重新参战。

建造层：
- 受击后**立刻朝伤害来源方向补墙**（有冷却，不会瞬发无敌）。
- 交战中概率性搭掩体。
- 卡住时自动跳跃并反向横移脱困。

### 界面

- **大厅**：原创渐变背景、生涯记录卡片、设置面板（灵敏度 / AI 数量 / AI 难度 / FOV）、操作说明。
- **HUD**（单次 `_draw` 绘制）：
  - 护盾条 + 生命条、武器名与稀有度、弹匣/备弹、五格物品栏（按稀有度着色）。
  - 木材 / 石材 / 金属计数与当前建材。
  - 风暴阶段、状态文字与倒计时，存活人数。
  - **小地图**：风暴圈（当前 + 下一圈）、兴趣点、玩家朝向。
  - **动态准星**：开合幅度实时反映当前扩散。
  - 命中标记（爆头金色）、**浮动伤害数字**（跟随世界坐标）、击杀播报。
  - 建造面板：四种结构图标 + 建材 + 普通/简易模式。
  - **编辑网格叠加**：把 3×3 网格投影到墙上并高亮当前格。
- **暂停菜单**：灵敏度与 FOV 即时生效，可重开或返回大厅。
- **结算界面**：名次、淘汰数、存活时间、生涯累计，一键再来一局。

### 开局与对局流程

1. 大厅 → 开始比赛。
2. **自由落体**：从 185 m 高空下落，`WASD` 调整方向。
3. `空格` 提前展开滑翔翼，42 m 自动展开，落地产生尘土。
4. 落地搜刮：地面战利品自动拾取，宝箱按 `E` 搜索。
5. 采集：空手时左键挥击树木/岩石/金属堆获得材料。
6. 战斗、建造、编辑、转点。
7. 风暴分 8 阶段收缩，中心随机偏移。
8. 最后一人获胜，结算并写入本地档案。

|---|---|

| `Z` | 循环木材 / 石材 / 金属 |
| 滚轮 | 切换物品槽 |
| `Esc` | 暂停与设置 |

## 已知限制

- 全部资产为程序化几何与纯色材质，**没有贴图、骨骼动画、音效与音乐**。
- 没有联网、没有服务器权威、没有反作弊（按离线单机设计）。
- 没有载具、游泳、投掷物、精英守卫与金库。
- 没有 NavigationServer3D，AI 用直线 + 跳跃脱困，复杂室内路径仍可能卡住。
- 树木与建筑使用独立网格，未做 MultiMesh/LOD；降低 AI 数量可提升帧率。
- 没有导出的 `.exe`，当前是 Godot 工程包。

## 原创性说明

地图布局、兴趣点名称、武器名称与数值、角色外观、界面与音效均为原创。
本项目仅借鉴「中心高价值区 + 外围主题据点 + 缩圈 + 即时建造」这类**通用玩法结构**，
未使用或复制任何既有游戏的地图几何、角色、贴图、音频、商标或专有数据表。
