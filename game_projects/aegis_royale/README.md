# Aegis Royale Prototype

完全离线的原创建造大逃杀项目，兼容官方预编译 **Godot 4.5.1 stable**。项目已经通过稳定版编辑器导入和自动进入比赛的运行时冒烟测试。

## 正确启动方式

1. 下载官方预编译 Godot 4.5.1 stable（建议使用 Standard 版）。
2. 解压项目 ZIP。
3. 打开 Godot Project Manager。
4. 点击“导入”，选择项目目录中的 `project.godot`。
5. 等待第一次扫描和脚本注册完成。
6. 打开项目后点击右上角运行按钮，或按 `F6/F5`。
7. 在大厅点击“开始离线比赛”。

`project.godot` 是项目配置文件，不是游戏可执行文件。直接双击它是否启动取决于系统文件关联；最可靠方式始终是从 Project Manager 导入。

- 后坐力、移动扩散、瞄准收束、爆头、距离衰减和火箭爆炸。

## 操作

- `WASD`：移动；空投阶段调整方向
- `Shift`：冲刺
- `Space`：跳跃；展开滑翔装置
- 左键：射击、采集、使用或建造
- 右键：瞄准
- `R`：换弹
- `E`：搜索容器
- `Q`：战斗/建造模式
- 战斗模式 `1–5`：物品槽
- 建造模式 `1–4`：墙、地板、斜坡、锥顶
- `F`：编辑己方结构
- `G`：旋转结构
- `V`：简易模式
- `Z`：切换木/石/金属
- `Esc`：暂停菜单
