# Aegis Royale Prototype

这是一个位于 Godot 4.8 源码仓库中的独立、完全离线的原创建造大逃杀工程。目标是验证完整的单局循环、模块化建造/编辑和战术 AI。它不导入或复制第三方游戏的地图文件、角色、美术、声音、商标或专有界面资产。

## 当前可玩内容

- 原创大厅、本地生涯统计、暂停菜单与离线设置档案
- 自由落体、手动展开滑翔装置和落点选择
- 原创岛屿：中央湖、四向河网、道路、桥梁和 9 个主题兴趣点
- 1 名玩家加最多 63 名可配置 AI；默认 31 名 AI
- 五槽物品栏、五类弹药、治疗与护盾物品
- 12 类原创武器及普通到特制的稀有度体系
- 地面战利品、普通/高级容器及随机掉落
- 木材、石材、金属采集和差异化建筑耐久/成型时间
- 墙、地板、斜坡和锥顶建造
- 蓝/红建造预览、距离检查、重复占位检查和基础支撑检查
- 墙体 3×3 单元几何、窗口、左右门、半墙和拱形编辑预设
- 普通与简易建造/编辑模式
- 动态缩圈、偏移安全区、圈外阶段伤害
- AI 搜刮、武器评估、安全区转点、治疗、控距、横移、搭墙、建盒和墙斜坡推进
- 武器瞄准收束、移动扩散、连续射击扩散、后坐力、爆头与距离衰减
- 火箭投射物、范围爆炸与结构伤害
- 动态准星、命中标记和暴击伤害反馈
- 最后生还者判定、玩家淘汰统计、排名结算、重新开始和本地比赛记录

## 启动

使用本仓库编译出的 Godot 4.8 编辑器导入：

`game_projects/aegis_royale/project.godot`

然后运行主场景。

## 操作

- `WASD`：移动；空投阶段调整滑翔方向
- `Shift`：冲刺
- `Space`：跳跃；空投阶段展开滑翔装置
- 鼠标左键：射击、使用、采集或放置结构
- 鼠标右键：瞄准并收束扩散
- `R`：换弹
- `E`：搜索容器
- `Q`：切换战斗和建造
- 战斗模式 `1–5`：选择物品槽
- 建造模式 `1/2/3/4`：墙 / 地板 / 斜坡 / 锥顶
- `G`：旋转结构
- `F`：编辑准星指向的己方结构
- `V`：切换简易建造与简易编辑
- `Z`：循环选择木材、石材和金属
- `Esc`：打开暂停和离线设置菜单

建造预览为蓝色时可以放置，红色表示材料不足、距离过远、重复占位或缺乏基础支撑。普通编辑按预设循环；简易编辑根据瞄准墙体的位置自动选择窗口、左门、右门或半墙。

## Release 发行包

当前版本号为 `0.3.0-alpha`。独立项目包命名为：

`AegisRoyale-0.3.0-alpha-GodotProject.zip`

发行包只包含 `game_projects/aegis_royale` 项目，不包含整个 Godot 引擎源码。`RELEASE_NOTES.md` 提供版本说明，SHA-256 文件用于校验包完整性。

仓库连接当前没有写入 `.github/workflows/` 的权限，因此自动 Release 工作流暂存为：

`release_workflow_template.yml`

获得 GitHub Actions workflow 写权限后，将它复制为 `.github/workflows/aegis_royale_release.yml`，即可在项目更新时自动打包并发布到 `aegis-royale-latest` Release，也可以手动指定正式版本标签。

## 主要脚本

- `main.gd`：大厅、离线档案、比赛装配
- `map_generator.gd`：原创岛屿、河网、道路、兴趣点与战利品分布
- `player.gd`：移动、射击手感、搜刮、采集、建造、预览和编辑
- `combat_projectile.gd`：火箭运动、碰撞、爆炸衰减和范围伤害
- `inventory.gd` / `item_database.gd`：物品栏、武器池、稀有度、弹药和消耗品
- `build_piece.gd` / `build_preview.gd`：结构几何、成型、编辑和合法性反馈
- `tactical_bot.gd`：AI 战略状态、风暴转点、搜刮、治疗和建造战术
- `storm_controller.gd`：多阶段偏移安全区
- `drop_controller.gd`：自由落体与滑翔
- `match_controller.gd`：胜负、淘汰归因、排名和结算
- `pause_menu.gd` / `local_profile.gd`：暂停设置、本地 JSON 配置与统计
- `hud.gd`：状态、动态准星、命中反馈、风暴、存活人数和滑翔提示

## 当前边界

当前版本仍是代码驱动的灰盒 Alpha。尚需继续补齐动画状态机、音频、完整枪口/弹道特效、地图高差与室内结构、导航网格、精英据点和金库、结构抢占、真正的编辑选格界面、AI 开门/跨水/路径恢复、手柄重绑定和平台可执行文件导出。

工程按完全离线游戏设计，不计划投入服务器、网络同步、客户端预测或反作弊系统。详细完成定义参见 `GAME_DESIGN.md`，技术边界参见 `ARCHITECTURE.md`。
