# Aegis Royale 设计基线

## 产品目标

完全离线、单人对 AI 的第三人称建造大逃杀。单局 15–22 分钟。
核心体验：高空落点选择 → 落地搜刮 → 采集材料 → 枪战与即时建造互相交织 → 缩圈决胜。
所有资产原创。

## 单局闭环

1. 大厅选择设置并开始。
2. 185 m 自由落体，观察地形选择落点，`空格` 提前开伞。
3. 落地抢夺地面战利品与宝箱。
4. 搜索武器、弹药、恢复品。
5. 破坏环境获得木/石/金属，用结构取得空间优势。
6. 根据风暴、装备、材料、附近交火决定搜刮 / 转点 / 交战。
7. 中后期连续缩圈与高频建造战。
8. 最后一名存活者获胜，写入本地生涯。

## 地图设计原则

采用 **中心高价值区 + 外围主题据点 + 普通聚落 + 道路连接** 的通用节奏，
不复制任何既有地图轮廓或坐标。

- **中央 T3**：曙光中枢，城市建筑群 + 仓库 + 瞭望塔，最高掉落密度。
- **外围 T2**：岬角通信站、苍穹能源站、苇影研究园、晴湾度假区、望海灯塔，主题明确、地形差异大。
- **外围 T1**：北境农场、赤潮工业港、松风镇、镜湖社区，资源密集但装备一般。
- **野外**：26 座填充建筑 + 植被 + 采集点，承担转点与随机遭遇。
- 道路连接主要据点，并削平地形，形成可预测的快速转点路线。

## 武器定位

| 类别 | 定位 | 交战距离 |
|---|---|---|
| 步枪 | 通用中距离 | 15–60 m |
| 霰弹枪 | 近战爆发、拆板 | 0–12 m |
| 冲锋枪 | 贴脸压制 | 0–20 m |
| 手枪 | 落地过渡 | 0–25 m |
| 狙击枪 | 远距离高伤 | 60 m+ |
| 轻机枪 | 持续压制拆板 | 10–40 m |
| 爆炸武器 | 反建造、范围 | 10–60 m |

稀有度提升伤害、降低换弹时间，并按权重影响掉落。

## 建造与编辑

- 网格：平面 4 m，垂直 3 m。
- 结构：墙（占格边）、地板、斜坡、锥顶（上层屋顶）。
- 材料：木材（快、150 耐久）、石材（中、300）、金属（慢、500）。
- 预览：蓝色可放置，红色不可放置并说明原因。
- 连发建造：按住左键，0.075 s 节流。
- 编辑：墙与地板为 3×3 单元；对准己方结构按 `F` 进入编辑，屏幕叠加网格，左键开关格，`F` 确认，`Esc` 还原。
- 预设：完整 / 窗口 / 门 / 拱门 / 半墙 / 低墙 / 左门 / 右门 / 支柱 / 阶梯。
- 普通模式：手动选择结构与建材。
- 简易模式：`V` 开关，放板更贴近角色、旋转步进更粗，便于快速自保。

## AI 能力层级

AI 不读取隐藏信息，不使用完美瞄准。

- **感知**：视锥、视距、视线遮挡、目标记忆、反应延迟、瞄准误差、弹道提前量。
- **生存**：搜刮、换枪、治疗、补弹、采集、躲避风暴。
- **战斗**：距离管理、横移、后撤、掩体、爆发射击节奏、武器切换。
- **建造**：受击补墙、交战掩体、墙+斜坡抢高、低血四面建盒。
- **战略**：评估风暴、装备、材料、附近交火与剩余人数，选择搜刮/转点/交战。
- **个性**：均衡 / 激进 / 建造型 / 远射型 / 谨慎，叠加连续技能值。

## 离线优先取舍

不实现网络同步、专用服务器、客户端预测、回滚、反作弊。
预算全部投入战斗手感、建造编辑、AI、地图与界面。
